# Yerel kabul ve teslim kontrolü

## Tamamlanan kaynak kontrolleri

- [x] Sekiz ürün görseli mevcut; JSON'daki yollar dosyalarla eşleşiyor.
- [x] Görseller ve JSON pubspec.yaml içinde kayıtlı.
- [x] Ana sayfa bannerında ürün görselleri kullanılıyor.
- [x] README: proje adı, açıklama, sürüm ve çalıştırma adımları mevcut.
- [x] Yerel Flutter 3.38.5 / Dart 3.10.4 sürümü sorguyla doğrulandı.
- [x] Birim testleri ve uygulama akış testleri mevcut.
- [x] Ekran görüntüsü üretimi için doğrulama betiği hazır.
- [x] Dart kaynakları biçimlendirildi.

## Yerel çalıştırma ile doğrulanacaklar

- [ ] flutter analyze ve flutter test başarılı.
- [ ] Ana sayfadan katalog açılıyor; geri tuşu çalışıyor.
- [ ] Sekiz ürün görünüyor; kategori seçimi ve arama birlikte çalışıyor.
- [ ] Boş arama sonucu ve arama temizleme doğru çalışıyor.
- [ ] Detayda doğru görsel, açıklama ve fiyat görünüyor.
- [ ] Katalog ve detaydan eklenen ürünler aynı sepette toplanıyor.
- [ ] Artır/azalt toplamı değiştiriyor; son adet kaldırıldığında ürün siliniyor.
- [ ] Temizleme iptali sepeti koruyor; onay sepeti boşaltıyor.
- [ ] Demo sepet butonu gerçek ödeme olmadığını açıklıyor.
- [ ] Uygulama yeniden başladığında sepet boşalıyor.
- [ ] Android cihaz/emulatörde ve büyük metin ayarında taşma yok.

## Zorunlu teslim

- [ ] Ana sayfa, katalog, detay ve dolu sepet görüntüleri üretildi ve görsel olarak kontrol edildi.
- [ ] Görüntüler docs/screenshots klasörüne eklendi.
- [ ] Proje public GitHub repository olarak paylaşıldı.
- [ ] Gerçek repository URL'i README'ye eklendi.

Çalıştırılmamış kontroller başarılı olarak işaretlenmez. Bu ortamda SDK/bağımlılık erişim kısıtları nedeniyle analiz, test ve cihaz doğrulaması tamamlanamadı. Yönergeye göre GitHub URL'i ve ekran görüntüleri olmadan teslim tamamlanmış sayılmaz.
